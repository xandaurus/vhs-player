# VHS Player — Local Tape Emulator

# Автор и разработчик: Александр Орёл

Полноценный эмулятор видеомагнитофона в браузере.

Выбираешь любое локальное видео → оно сразу играет с тяжёлыми VHS-эффектами (WebGL-шейдер) + деградацией звука.

## Что умеет

**Видео (WebGL):**
- Tracking errors / плавающие горизонтальные полосы
- Per-line jitter
- Head-switching noise внизу кадра
- Chroma shift + bleed
- Scanlines
- Grain + sparkle (сильнее в тёмных местах)
- Tape wave
- Лёгкая десатурация и тёплый оттенок
- Vignette

**Звук (Web Audio API):**
- Low-pass + high-pass (имитация ограниченной полосы VHS)
- Постоянный tape hiss
- Компрессия
- Интенсивность шума и среза частот завязана на слайдеры

**Управление:**
- Drag & drop или кнопка выбора файла
- Play / Pause / Stop / ±10 сек
- Слайдеры: Tracking, Noise, Chroma, Wear
- Клавиатура: Space, ← →

## Как запустить

Просто открой `index.html` в современном браузере  
или залей папку на GitHub Pages.

```bash
# локально с сервером (рекомендуется)
npx serve .
# или
python -m http.server 8080
```

## Заметки

- Лучше всего работает в Chrome / Firefox / Edge.
- Safari иногда капризничает с WebGL + video texture.
- На слабых устройствах можно уменьшить значения слайдеров.
- Для максимального реализма можно позже добавить более сложный wow/flutter через DelayNode.
